# UN평화축제 부스 운영: 1분 평화 카드 찾기

방문객이 1분 동안 유엔평화기념관 홈페이지(unpm.or.kr/un2022)를 둘러보며 숨은 6·25전쟁 참전국 카드 20장을 찾는 체험이다.
- 확장 프로그램만으로 동작한다. 서버와 Docker는 필요 없다.
- 인터넷은 기념관 홈페이지에 접속할 때만 필요하다. 휴대폰 핫스팟을 예비로 준비한다.
- 노트북이 여러 대여도 각자 따로 동작한다. 랭킹은 없다.

## 설치 (노트북마다)
1. 빌드한다.
   ```bash
   cd frontend && npm install && npm run build
   ```
2. 크롬에서 `chrome://extensions`를 열고 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `frontend/build/chrome-mv3-prod` 폴더를 고른다.
4. 확장 아이콘을 누르고 팝업 맨 위의 **🕊️ 1분 평화 카드 찾기**를 누르면 부스 화면 탭이 열린다. 이 탭은 **닫지 말고 고정**해 둔다.

부스 전용 크롬 프로필을 따로 만들어 쓰면 개인 계정과 탭이 방문객에게 보이지 않는다.

## 운영 순서
1. **대기**: 부스 화면에 방법과 20개국 힌트가 보인다. 기다리는 사람은 힌트를 읽는다.
2. **시작**: [시작하기]를 누르면 3·2·1 뒤 기념관 홈페이지가 새 탭으로 열리고 1분이 시작된다.
3. **찾기**
   - 오른쪽 아래에 남은 시간과 찾은 수가 보인다. [힌트]를 누르면 나라별 힌트가 열린다.
   - 카드가 있는 페이지에 들어가면 카드가 떠오르고, 클릭하면 모인다.
4. **종료**
   - 1분이 지나면 "시간 종료!"가 뜬다.
   - 게임 중에 열린 탭은 자동으로 닫히고, 부스 화면이 결과를 보여 준다.
   - 결과는 찾은 장수와 20장 격자다. 찾은 카드는 컬러, 못 찾은 카드는 흑백이다.
5. **상품**: 찾은 장수를 보고 상품을 준다.
6. **다음 사람**: [다음 사람]을 누르면 기록이 지워지고 대기 화면으로 돌아간다.

**운영 팁**
- 진행 중에 부스 화면 탭으로 돌아오면 [기념관 화면으로]와 [그만하기]가 있다.
- 게임 중에 새로 연 탭은 끝날 때 모두 닫힌다. 운영용 탭은 다른 창에서 연다.
- 부스 화면 탭을 실수로 닫아도, 시간이 끝나면 기념관 탭이 스스로 결과 화면으로 넘어간다. 팝업 버튼으로 다시 열어도 된다.

## 축제 직전 점검 (필수)
새 글이 올라오면 카드 글이 목록 뒤로 밀린다. 특히 다음 카드를 확인한다.
- 소식·보도·교육사진·활동사진 게시판: 덴마크·에티오피아·뉴질랜드·태국
- 목록 1쪽 끝자리: 필리핀·인도

```bash
cd frontend && npm run check:festival
```

- 20장 모두 ✓이면 그대로 쓴다.
- ✗(3쪽 이상으로 밀렸거나 사라짐)가 나오면 다음 순서로 고친다.
  1. `frontend/festival/cards.ts`에서 그 카드의 `menuId`·`bCode`·`boNo`를 같은 나라 이야기가 있는 가까운 글로 바꾼다. 예: 이달의 참전국의 그 나라 글.
  2. `npm run build`를 하고 확장을 다시 로드한다.

## 테스트
```bash
cd frontend
npm run test:festival
npm run build && npm run e2e:festival
```

- `test:festival`은 주소 매칭과 시간 계산을 검사한다.
- `e2e:festival`은 헤드리스 크롬에 확장을 설치해 시작 → 덴마크 카드 줍기 → 종료 → 결과 → 다음 사람까지 확인한다. 실제 기념관 사이트에 접속하므로 인터넷이 필요하다.
- 테스트할 때는 `tabs/festival.html?sec=15`처럼 게임 시간을 줄일 수 있다(5~600초).

## 문제 해결
- **카드가 안 뜬다**
  - 오른쪽 아래 시간 표시가 없으면 게임이 진행 중이 아닌 것이다.
  - 확장을 다시 로드했다면 기념관 탭을 새로고침한다.
- **콘솔에 `tts_setCookie is not defined`가 보인다**: 기념관 사이트 자체 오류다. 게임과 관계없다.
- **카드 그림을 바꾸고 싶다**: `frontend/assets/festival/festival_card_{코드}.webp`(810×480)를 같은 이름으로 바꾸고 다시 빌드한다.
